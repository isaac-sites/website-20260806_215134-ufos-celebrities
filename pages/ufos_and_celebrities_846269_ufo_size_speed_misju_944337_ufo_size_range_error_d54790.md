## Introduction

Reports of UFOs often describe objects that seem astonishingly large. Yet an eyewitness usually perceives only how wide an object appears in the sky, not its true physical dimensions. Converting that apparent width into metres requires one crucial piece of information: the object's distance. If that distance is guessed incorrectly, every estimate of the object's size scales with the error. A nearby light mistaken for something kilometres away can become an apparently gigantic craft, even though the visual appearance has not changed. This simple geometric relationship is one of the main reasons investigators treat eyewitness size estimates cautiously, especially when observations involve isolated lights or featureless shapes rather than recognisable aircraft.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/Information%20Papers/AARO_Effect_of_Forced_Perspective_and_Parallax_View_on_UAP_Observations_2024.pdf?ver=WTwJtQaCvC3BkRlBJCGLzg%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">Effect of Forced Perspective and Parallax View on UAP Observations</span><span class="citation-popover-snippet">Effect of Forced Perspective and Parallax View on UAP ObservationsMay 8, 2024...</span><span class="citation-popover-meta">Published: May 8, 2024</span></span></span>

## Angular Size Versus Physical Size

Human vision naturally measures **angular size**—how much of the field of view an object occupies. Physical size is a different quantity entirely.

A familiar demonstration is the Moon. Holding a fingertip or a small coin at arm's length can completely cover it, despite the Moon being more than 3,400 kilometres across. The eye simply registers that both objects subtend roughly the same angle.

The same principle applies to reported UFOs. A bright object occupying one degree of the sky could be:

## How an Assumed Distance Multiplies the Estimated Size

The relationship between angular size and physical size is approximately linear for the small angles typical of distant aerial observations:

**Physical size ≈ distance × angular size**<span class="citation-chip-wrap"><a class="citation-chip" href="https://ntrs.nasa.gov/citations/20040172655" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ntrs.nasa.gov">[ntrs.nasa.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ntrs.nasa.gov</span><span class="citation-popover-snippet">Source details in endnotes.</span></span></span>

This has an important consequence: if the assumed distance doubles, the inferred size also doubles. If the assumed distance is ten times too great, the estimated diameter becomes roughly ten times too great as well.

Imagine a bright sphere that appears to span a small angle in the sky:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* If it is actually 100 metres away, it might only be about one metre across.
* If a witness instead assumes it is 1 kilometre away, the same apparent width now implies an object around ten metres across.
* If it is mentally placed several kilometres away against distant clouds, the estimate can grow into the dimensions of a large aircraft or larger.

</div>

Nothing about the image reaching the observer's eyes has changed. Only the assumed range has.

This explains why witnesses describing the same visual appearance can arrive at dramatically different estimates of a UFO's size depending on where they believe it was located.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/Information%20Papers/AARO_Effect_of_Forced_Perspective_and_Parallax_View_on_UAP_Observations_2024.pdf?ver=WTwJtQaCvC3BkRlBJCGLzg%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">Effect of Forced Perspective and Parallax View on UAP Observations</span><span class="citation-popover-snippet">Effect of Forced Perspective and Parallax View on UAP ObservationsMay 8, 2024...</span><span class="citation-popover-meta">Published: May 8, 2024</span></span></span>

## Why Featureless Objects Defeat Familiar Size Cues

People normally estimate distance by comparing unfamiliar objects with familiar ones. Buildings, trees, aircraft wings, vehicles and people all provide known scales that help the brain judge depth.

Many reported UFOs remove those reference points.

Witnesses commonly describe:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* glowing points of light,
* smooth luminous spheres,
* dark silhouettes,
* discs without visible windows or markings,
* objects seen against an empty night sky.

</div>

Without recognisable features, the visual system has little information for estimating distance. The All-domain Anomaly Resolution Office ([AARO]({{ 'aaro/' | relative_url }})) notes that size and distance errors become much more likely when an object lacks identifiable features such as wings, windows or propellers. Observers then rely on assumptions or comparisons with clouds, treetops or buildings, which themselves may be at uncertain distances.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/Information%20Papers/AARO_Effect_of_Forced_Perspective_and_Parallax_View_on_UAP_Observations_2024.pdf?ver=WTwJtQaCvC3BkRlBJCGLzg%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">Effect of Forced Perspective and Parallax View on UAP Observations</span><span class="citation-popover-snippet">Effect of Forced Perspective and Parallax View on UAP ObservationsMay 8, 2024...</span><span class="citation-popover-meta">Published: May 8, 2024</span></span></span>

AARO illustrates how forced perspective can produce substantial errors in perceived size. If an observer incorrectly judges where an unidentified object sits relative to background references, the estimated dimensions change even though the object's apparent angular size remains constant.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/Information%20Papers/AARO_Effect_of_Forced_Perspective_and_Parallax_View_on_UAP_Observations_2024.pdf?ver=WTwJtQaCvC3BkRlBJCGLzg%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">Effect of Forced Perspective and Parallax View on UAP Observations</span><span class="citation-popover-snippet">Effect of Forced Perspective and Parallax View on UAP ObservationsMay 8, 2024...</span><span class="citation-popover-meta">Published: May 8, 2024</span></span></span>

## Why Clouds Often Mislead Witnesses

Clouds are particularly deceptive because their distances are rarely obvious to casual observers.

A light may appear:


<div class="content-enhancement content-enhancement--phrase-pills" markdown="1">

* embedded within a cloud,
* just beyond a cloud,
* or silhouetted against it.

</div>

Yet the light may actually be far closer than the cloud layer.

If a witness unconsciously places the object at cloud distance, the implied physical size increases enormously. Conversely, a distant object mistaken for something much nearer will appear much smaller than it really is.

Because the sky provides few fixed depth cues, even experienced observers can misjudge these relationships from a single viewing position. The apparent alignment of an object with a cloud or mountain does not reliably establish that they occupy the same distance.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/Information%20Papers/AARO_Effect_of_Forced_Perspective_and_Parallax_View_on_UAP_Observations_2024.pdf?ver=WTwJtQaCvC3BkRlBJCGLzg%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">Effect of Forced Perspective and Parallax View on UAP Observations</span><span class="citation-popover-snippet">Effect of Forced Perspective and Parallax View on UAP ObservationsMay 8, 2024...</span><span class="citation-popover-meta">Published: May 8, 2024</span></span></span>

## Why Different Witnesses Can Describe Different Sizes

Two people observing the same unidentified object may sincerely report very different dimensions.

Each observer brings different assumptions about:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* how far away the object was,
* whether it was above nearby landmarks or beyond them,
* and which background reference seemed most plausible.

</div>

Since the estimated size depends directly on the estimated distance, different assumptions naturally produce different physical dimensions even when both witnesses observed the same angular appearance.

This helps explain why reports sometimes describe an object as anything from "car-sized" to "the size of a football pitch" without requiring anyone to be deliberately exaggerating. The uncertainty often originates in estimating range rather than in describing what was actually seen.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/Portals/136/PDFs/Information%20Papers/AARO_Effect_of_Forced_Perspective_and_Parallax_View_on_UAP_Observations_2024.pdf?ver=WTwJtQaCvC3BkRlBJCGLzg%3D%3D" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">Effect of Forced Perspective and Parallax View on UAP Observations</span><span class="citation-popover-snippet">Effect of Forced Perspective and Parallax View on UAP ObservationsMay 8, 2024...</span><span class="citation-popover-meta">Published: May 8, 2024</span></span></span>

## Why Investigators Avoid Treating Eyewitness Size Estimates as Measurements

Modern investigations distinguish between what was directly observed and what was inferred.

A witness can reliably report observations such as:


<div class="content-enhancement content-enhancement--caution" markdown="1">

* where an object appeared in the sky,
* how bright it seemed,
* its colour,
* or how long it remained visible.

</div>

Statements such as "it was 300 metres wide" are different. They are derived estimates that depend on assumptions about distance. Unless range can be established independently—through multiple calibrated cameras, radar, stereo imagery or other corroborating measurements—the true physical size cannot be calculated with confidence.

For this reason, both NASA and AARO emphasise collecting better sensor data and multiple viewpoints rather than relying solely on visual impressions. Improved distance measurements reduce uncertainty not only in estimated size but also in later calculations of speed, acceleration and manoeuvrability, all of which depend on knowing where the object actually was.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://science.nasa.gov/uap/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: science.nasa.gov">[NASA Science]</a><span class="citation-popover" role="note"><span class="citation-popover-source">science.nasa.gov</span><span class="citation-popover-title">Science UAP</span><span class="citation-popover-snippet">NASA ScienceUAP - NASA Science...</span></span></span>

    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
