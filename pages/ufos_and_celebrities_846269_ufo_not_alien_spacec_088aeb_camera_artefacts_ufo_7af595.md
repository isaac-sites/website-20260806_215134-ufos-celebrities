## Introduction

A genuine video of an aircraft can still look deeply mysterious because cameras do not record the world exactly as human eyes see it. Modern imaging systems compress video, stabilise motion, sharpen edges, stretch contrast and, in the case of infrared (IR) sensors, convert heat into a visible image. Each stage can introduce artefacts that change how an ordinary aircraft appears on screen. The result may be an object that seems to rotate, leave an impossible trail, accelerate suddenly or adopt an unfamiliar shape even though none of those features exist in the real scene.

Investigators increasingly examine the camera system itself as carefully as the object being filmed. ## Common artefacts in compressed and infrared video

### Compression can create false wakes and unusual shapes

Digital video compression predicts what successive frames should look like instead of storing every pixel independently. This works well for ordinary scenes but struggles with tiny, fast-moving objects against relatively featureless backgrounds such as the sky.

Compression artefacts may produce:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Apparent vapour trails that do not exist.
* Smearing behind moving aircraft.
* Blocky or elongated shapes.
* Flickering edges that resemble energy emissions.
* Brief distortions during rapid camera motion.

</div>

A well-known official example comes from footage released by the US All-domain Anomaly Resolution Office ([AARO]({{ 'aaro/' | relative_url }})). An MQ-9 drone recorded what initially appeared to be an unusual object leaving an atmospheric wake. After analysing the complete video, examining higher-magnification imagery and comparing the timing with commercial flight records, AARO concluded the object was probably a commercial aircraft. The apparent trailing wake was assessed as a video-compression artefact rather than a physical phenomenon.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

This illustrates an important investigative principle: [authentic footage]({{ 'authenticity/' | relative_url }}) can still display visual effects created by the recording system rather than by the object itself.

### Infrared displays are not ordinary photographs

Forward-looking infrared (FLIR) systems convert heat differences into monochrome images. Automatic adjustments continually stretch or compress brightness to keep targets visible.

These automatic corrections can produce misleading impressions:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Hot engine exhaust may dominate the image while the aircraft body almost disappears.
* Atmospheric humidity and temperature gradients may distort apparent shape.
* Display polarity changes can reverse light and dark regions.
* Small thermal variations may suddenly become exaggerated when contrast is automatically adjusted.

</div>

Because viewers are accustomed to interpreting visible-light photographs, these thermal images are often misunderstood as literal pictures of solid objects.

### Stabilisation and tracking can create apparent motion

Many military and civilian imaging systems actively track targets while compensating for aircraft vibration or operator movement.

If the tracking software momentarily loses lock, the target may appear to:

* Jump sideways.
* Accelerate abruptly.
* Zigzag.
* Pause unexpectedly.
* Reverse direction.

In reality, the object may have continued along a smooth path while the camera repeatedly corrected its own pointing direction.

### Rotation may belong to the camera, not the object

Some of the most famous UAP videos appear to show rotating or tumbling objects. However, the apparent rotation is not always evidence that the object itself is turning.

As tracking systems rotate their optics to maintain lock on a target, lens characteristics, glare patterns and sensor geometry can rotate with the camera. Bright infrared sources may therefore appear to spin even if the aircraft remains stable.

This is why investigators distinguish between movement of the target and movement introduced by the imaging system before drawing conclusions about unusual flight behaviour.

## Why distance makes artefacts more convincing

Aircraft observed at long range occupy very few pixels. A large commercial jet several kilometres away may cover only a tiny portion of an infrared frame.

When an object is represented by so little information:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* Minor processing changes affect its apparent shape dramatically.
* Compression errors become proportionally larger.
* Atmospheric turbulence distorts individual frames.
* Automatic sharpening exaggerates edges.
* Noise-reduction algorithms merge nearby pixels into unfamiliar forms.

</div>

As the amount of original visual information decreases, the influence of image processing increases. The video may faithfully record what the sensor produced while still failing to represent the aircraft's true appearance.

## Real examples show why context matters

Official investigations increasingly combine imagery with external information rather than analysing video alone.

For example, AARO has demonstrated that additional evidence—including longer recordings, higher-magnification footage, aircraft tracking data, pixel-level examination and knowledge of sensor characteristics—can transform apparently extraordinary clips into ordinary aircraft observations affected by imaging artefacts. In another published case involving infrared footage over the Mediterranean near Mount Etna, AARO concluded that intense atmospheric conditions around the volcanic plume produced optical distortions that made the recorded object appear to pass through the plume when detailed analysis showed otherwise.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.aaro.mil/UAP-Cases/Official-UAP-Imagery/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: aaro.mil">[AARO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">aaro.mil</span><span class="citation-popover-title">UAP Imagery</span><span class="citation-popover-snippet">AARO UAP Imagery...</span></span></span>

These cases do not imply that every unresolved video has a mundane explanation. Rather, they demonstrate that seemingly remarkable visual behaviour can emerge from well-understood interactions between cameras, atmosphere and digital processing.

## Why original files and sensor data matter

Publicly shared clips are often heavily compressed versions of the original recording. Important diagnostic information may already have been lost before independent analysts see the footage.

Investigators therefore place much greater value on:


<div class="content-enhancement content-enhancement--metric" markdown="1">

* Original, uncompressed recordings.
* Exact camera and sensor specifications.
* Frame timing and metadata.
* Aircraft position and orientation.
* Zoom level and lens settings.
* Multiple sensors observing the same event.
* Radar or flight-tracking information.

</div>

## What this means for interpreting UFO videos

Camera artefacts do not mean that every unusual recording is explained, nor do they imply that witnesses are mistaken. They show that modern imaging systems introduce their own visual effects, particularly when recording distant aircraft through infrared sensors or heavily compressed video streams.

For that reason, investigators first ask whether apparent wakes, rotations, strange outlines or abrupt manoeuvres originate from the object or from the camera system. Only after accounting for optical effects, compression, stabilisation and sensor behaviour can the remaining evidence be assessed. This careful approach explains why many initially puzzling UFO videos are eventually identified as ordinary aircraft whose appearance was transformed by the technology used to record them.

    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
