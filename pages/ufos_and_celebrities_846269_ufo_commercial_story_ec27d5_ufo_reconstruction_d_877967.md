## Introduction

Television reconstructions are often the most memorable part of a UFO programme, but they are not the same thing as the original testimony. To turn an eyewitness account into a watchable sequence, producers must decide what the object looked like, how it moved, what colour it was, how large it appeared, where the camera should be positioned and what surrounding details to include. Those choices can make an uncertain description appear visually precise. Over time, viewers—and sometimes even later witnesses discussing the event—may remember the reconstruction as if it were part of the original evidence rather than a production team's interpretation. Research on [eyewitness memory]({{ 'eyewitness-memory/' | relative_url }}) helps explain why this happens: human memory is reconstructive rather than a literal recording, making it vulnerable to later information, repetition and vivid imagery.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ojp.gov/ncjrs/virtual-library/abstracts/reconstructive-memory-processes-eyewitness-testimony-trial-process" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ojp.gov">[ojp.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ojp.gov</span><span class="citation-popover-title">reconstructive memory processes eyewitness testimony trial process</span><span class="citation-popover-snippet">Office of Justice ProgramsReconstructive Memory Processes in Eyewitness Testimony (From Trial Process, P 115-144, 1981, Bruce D Sales, ed...</span></span></span>

## Why vague testimony becomes visually specific

Most eyewitnesses do not report cinematic levels of detail. A witness might describe "a bright object", "a dark shape" or "something hovering", while remaining uncertain about its exact outline, surface texture or motion. Television, however, cannot easily present ambiguity for several minutes. A reconstruction therefore fills in the missing information.

Common production decisions include:

* Choosing a definite shape, such as a classic disc, triangle or glowing sphere.
* Assigning colours or lighting effects that the witness never specified.
* Showing smooth, dramatic movements instead of uncertain or intermittent motion.
* Fixing the object's distance, size and angle despite the witness expressing uncertainty.
* Presenting a single viewpoint even when multiple observers described different perspectives.

None of these choices necessarily reflects deliberate deception. They are practical decisions required to create a coherent visual sequence. The problem arises when those artistic decisions become psychologically associated with the original account.

This issue is well understood in eyewitness research. Elizabeth Loftus and other researchers have shown that information introduced after an event can become integrated into a person's recollection, especially when the original memory contained gaps or uncertainty. Later information does not simply sit alongside the original experience; under some conditions it becomes incorporated into what people sincerely believe they saw.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ojp.gov/ncjrs/virtual-library/abstracts/reconstructive-memory-processes-eyewitness-testimony-trial-process" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ojp.gov">[Office of Justice Programs]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ojp.gov</span><span class="citation-popover-title">reconstructive memory processes eyewitness testimony trial process</span><span class="citation-popover-snippet">Office of Justice ProgramsReconstructive Memory Processes in Eyewitness Testimony (From Trial Process, P 115-144, 1981, Bruce D Sales, ed...</span></span></span>

## How repeated imagery reshapes viewer memory

Reconstructions influence more than the witnesses involved. They also shape how audiences remember the case.

Once a dramatic image has been seen repeatedly—through [documentaries]({{ 'documentaries/' | relative_url }}), streaming series, magazine illustrations or social media clips—it can become the mental "default" version of the incident. People recalling the case years later often remember the reconstruction rather than the original verbal description.

Psychological research identifies several mechanisms that make this possible.

**Visual concreteness.** Detailed images are easier to remember than verbal uncertainty. A glowing metallic craft hovering over trees leaves a stronger memory than "an unidentified object of uncertain shape."

**The misinformation effect.** Later information presented after an event can alter recall of the original event. Even when people believe they are remembering firsthand evidence, they may instead be recalling information acquired afterwards.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ojp.gov/ncjrs/virtual-library/abstracts/distortions-eyewitness-memory-postevent-information-part-3" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ojp.gov">[Office of Justice Programs]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ojp.gov</span><span class="citation-popover-title">distortions eyewitness memory postevent information part 3</span><span class="citation-popover-snippet">Office of Justice ProgramsDistortions in Eyewitness Memory From Postevent Information: Part 3: Eyewitness Testimony (From Criminal Behavi...</span></span></span>

**Repetition.** Research suggests that repeated exposure increases acceptance and confidence more reliably than simply hearing the same claim from multiple independent sources. A reconstruction shown repeatedly across documentaries, television specials and online clips may therefore become increasingly familiar and subjectively convincing.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.sciencedirect.com/science/article/pii/S000169181100223X" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: sciencedirect.com">[ScienceDirect]</a><span class="citation-popover" role="note"><span class="citation-popover-source">sciencedirect.com</span><span class="citation-popover-snippet">Repetition, not number of sources, increases both susceptibility to misinformation and confidence in the accuracy of eyewitn...</span></span></span>

These mechanisms help explain why some famous UFO cases acquire increasingly detailed popular imagery over decades despite the earliest witness statements being comparatively restrained.

## When reconstructions become mistaken for evidence

The greatest risk is not that viewers recognise a reconstruction as fictional. It is that they gradually forget where the visual details originated.

A reconstruction may unintentionally introduce features such as:


<div class="content-enhancement content-enhancement--insight-grid" markdown="1">

* metallic panels or rivets;
* spinning or rotating motion;
* coloured lights arranged in a pattern;
* perfectly symmetrical geometry;
* silent hovering at a fixed height;
* dramatic acceleration viewed from impossible camera angles.

</div>

If those elements were production choices rather than reported observations, later discussions can become distorted. People may cite the object's apparent appearance or movement as though those characteristics came directly from eyewitness testimony.

This source-monitoring problem—remembering information while forgetting where it came from—is well documented in memory research. People often retain the content of later information while losing track of whether it came from personal experience, another person's account or a visual reconstruction.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ojp.gov/ncjrs/virtual-library/abstracts/reconstructive-memory-processes-eyewitness-testimony-trial-process" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ojp.gov">[Office of Justice Programs]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ojp.gov</span><span class="citation-popover-title">reconstructive memory processes eyewitness testimony trial process</span><span class="citation-popover-snippet">Office of Justice ProgramsReconstructive Memory Processes in Eyewitness Testimony (From Trial Process, P 115-144, 1981, Bruce D Sales, ed...</span></span></span>

Within commercial UFO [storytelling]({{ 'storytelling/' | relative_url }}), that distinction is particularly important because many cases rely heavily on eyewitness reports rather than extensive physical evidence.

## A feedback loop between witnesses and later media

The relationship can become circular.

An initial witness gives an uncertain description.

A television programme creates a detailed reconstruction.

That reconstruction becomes widely circulated.

Years later, interviews with witnesses—or with people who learned about the case through media coverage—may include visual details resembling the reconstruction rather than the earliest recorded testimony.

This does not necessarily imply dishonesty. Memory naturally changes through repeated recall, discussion and exposure to later information. Researchers studying eyewitness evidence have consistently found that memories evolve as people integrate additional information encountered after the original event.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.ojp.gov/ncjrs/virtual-library/abstracts/reconstructive-memory-processes-eyewitness-testimony-trial-process" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: ojp.gov">[Office of Justice Programs]</a><span class="citation-popover" role="note"><span class="citation-popover-source">ojp.gov</span><span class="citation-popover-title">reconstructive memory processes eyewitness testimony trial process</span><span class="citation-popover-snippet">Office of Justice ProgramsReconstructive Memory Processes in Eyewitness Testimony (From Trial Process, P 115-144, 1981, Bruce D Sales, ed...</span></span></span>

Discussions of long-running UFO incidents, including cases revisited decades after the original reports, often acknowledge that memories develop over time and that group discussion can reinforce a shared narrative without intentional fabrication. ## What responsible reconstructions should do

Reconstructions are not inherently misleading. They can help audiences understand witness positions, viewing angles or the sequence of reported events. The difficulty lies in presenting interpretation as observation.

Better practice includes:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* Clearly labelling every reconstruction as an artist's interpretation.
* Distinguishing reported details from inferred ones.
* Avoiding unnecessary specificity where testimony remains uncertain.
* Using narration that states when shape, colour or motion are unknown.
* Showing alternative visual possibilities if witnesses disagreed.
* Returning viewers to the original interview rather than allowing the reconstruction to become the dominant representation.

</div>

These practices preserve the useful explanatory role of re-enactments without allowing visual invention to replace documentary evidence.

## Why this matters for commercial UFO storytelling

Commercial productions naturally favour images that are memorable, emotionally engaging and visually coherent. Yet those same qualities can blur the boundary between evidence and illustration.

For UFO cases that depend heavily on eyewitness testimony, every added visual decision carries interpretive weight. A reconstruction may communicate certainty that the original witness never expressed, and repeated exposure can make those additions feel increasingly authentic. The resulting story can become richer than the evidence itself—not because anyone deliberately falsified events, but because television requires concrete images while eyewitness memories often remain incomplete and uncertain. Understanding that distinction allows viewers to appreciate reconstructions as storytelling devices rather than treating every visual detail as part of the historical record.

    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
